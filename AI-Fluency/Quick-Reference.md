# Quick Reference: The Complete AI Fluency Framework

---

## The Big Picture

```
AI Fluency = Engaging with AI in ways that are:
  ✅ Effective    — getting the right outcomes
  ✅ Efficient    — without wasting time or energy
  ✅ Ethical      — honestly and responsibly
  ✅ Safe         — protecting privacy, security, and people
```

---

## The Three Modes of AI Interaction

| Mode | Human Role | AI Role | Best For |
|------|-----------|---------|----------|
| **Automation** | Script writer | Executes defined tasks | Repetitive, well-defined work |
| **Augmentation** | Collaborator | Thinking partner | Complex, exploratory problems |
| **Agency** | Director | Autonomous operator | Ongoing, dynamic operations |

---

## The 4 Ds — Complete Framework

| D | Core Question | Sub-Concepts | Failure Looks Like |
|---|--------------|-------------|-------------------|
| **Delegation** | What work goes to AI vs. human? | Problem Awareness → Platform Awareness → Task Delegation | Using AI for the wrong tasks; missing human accountability |
| **Description** | How do I communicate clearly? | Product → Process → Performance Description | Vague prompts; wrong format; wrong tone; AI missing your intent |
| **Discernment** | Is this output actually good? | Product → Process → Performance Discernment | Bad outputs used unchecked; errors slip through |
| **Diligence** | Am I being responsible? | Creation → Transparency → Deployment Diligence | Data breaches; undisclosed AI use; unverified facts shared |

## Key Technical Concepts Reference

| Term | Simple Definition |
|------|------------------|
| **LLM** | Large Language Model — AI trained on massive text to generate language |
| **Transformer** | Neural network architecture (2017) that enabled modern LLMs |
| **Parameter** | Mathematical value inside a model; billions = richer capability |
| **Pre-training** | Learning language patterns from massive datasets |
| **Fine-tuning** | Additional training to make model helpful, harmless, honest |
| **RLHF** | Human feedback used to shape better model behaviour |
| **Context Window** | Maximum text the model can process at once; its "working memory" |
| **Token** | Basic unit of text (~0.75 words); context windows measured in tokens |
| **Hallucination** | Confident but false AI output; a known LLM limitation |
| **Knowledge Cutoff** | Training data end date; model unaware of events after this |
| **Temperature** | Controls randomness; low = consistent, high = creative |
| **RAG** | Retrieval Augmented Generation; connects AI to external knowledge |
| **Few-shot Prompting** | Providing examples in the prompt to guide output style |
| **Chain-of-thought** | Guiding AI to reason step by step for better results |
| **Non-deterministic** | Same input may produce different outputs each time |

## The Prompting Toolkit (6 Techniques)

| Technique | When to Use |
|-----------|------------|
| **Give Context** | Always — specify who you are, what you want, and why |
| **Show Examples (Few-shot)** | When style/format is hard to describe in words |
| **Specify Output Constraints** | When you have specific format, length, or structure requirements |
| **Break into Steps** | For complex, multi-step analysis or workflows |
| **Ask Claude to Think First** | For problems requiring careful reasoning |
| **Define Role/Tone** | When you need a specific expertise perspective |
| **Ask Claude to Improve Your Prompt** | When you are unsure how to structure your request |

## The Diligence Checklist

**Before using AI (Creation Diligence):**
- [ ] Is this AI tool approved by my organisation?
- [ ] What does the platform do with my input data?
- [ ] Does any data I am about to enter require special protection?
- [ ] Does this use case align with my professional and organisational ethics?

**During and after (Transparency Diligence):**
- [ ] Who needs to know that AI was involved in this work?
- [ ] When and how should I disclose this?
- [ ] Have I documented AI's involvement appropriately?

**Before sharing output (Deployment Diligence):**
- [ ] Have I verified all factual claims independently?
- [ ] Have I checked for potential bias in the output?
- [ ] Does this output meet the same quality standard as human-created work?
- [ ] Am I comfortable putting my professional name on this?

## Sub-Concepts at a Glance

### Delegation
| Sub-Concept | Key Questions |
|-------------|--------------|
| Problem Awareness | What am I trying to achieve? What does success look like? |
| Platform Awareness | Which AI suits this task? What are the data policies? |
| Task Delegation | What gets automated? What needs augmentation? What stays human-only? |

### Description
| Sub-Concept | What to Specify |
|-------------|----------------|
| Product Description | Format, length, audience, tone, required sections |
| Process Description | Methodology, order of steps, frameworks to apply |
| Performance Description | Persona, level of challenge, detail vs. conciseness |

### Discernment
| Sub-Concept | What to Look For |
|-------------|----------------|
| Product Discernment | Factual accuracy, appropriateness, completeness, fitness for purpose |
| Process Discernment | Logical errors, attention lapses, circular reasoning |
| Performance Discernment | Communication style, efficiency, responsiveness to feedback |

### Diligence
| Sub-Concept | Core Focus |
|-------------|-----------|
| Creation Diligence | Data ownership, platform policies, organisational approval |
| Transparency Diligence | Who needs to know, when and how to disclose |
| Deployment Diligence | Accuracy verified, bias checked, quality bar maintained |
